# Скриншоты SubGuard для портфолио

Загружайте PNG прямо на площадку, чтобы проект был понятен без перехода по ссылке.
Если разрешено только 4 изображения, возьмите пункты 1, 2, 4 и 6. Если разрешено
6 — добавьте пункты 3 и 5. Остальные показывают отдельные функции.

| № | Файл | Подпись под изображением |
|---|---|---|
| 1 | `portfolio-cover-ru.png` | SubGuard — контроль подписок и пробных периодов |
| 2 | `showcase-desktop-ru.png` | Обзор ближайших списаний и расходов по валютам |
| 3 | `showcase-subscriptions-ru.png` | Управление подписками: статусы, поиск, импорт CSV |
| 4 | `showcase-trial-form-ru.png` | Пробный период, первый платёж и дата отмены |
| 5 | `showcase-analytics-ru.png` | Аналитика подписок и записанных платежей |
| 6 | `showcase-mobile-ru.png` | Адаптивный интерфейс Mini App на телефоне |
| 7 | `showcase-refunds-ru.png` | Учёт обращения за возвратом |
| 8 | `showcase-bot-simulation-ru.png` | Симуляция Telegram-бота для показа сценария; не живой бот |
| 9 | `showcase-landing-ru.png` | Полная стартовая страница со схемой проверки |

Все скриншоты сделаны из статической витрины с вымышленными данными. Это изображения
интерфейса, а не свидетельство публичного запуска FastAPI/PostgreSQL/Telegram.
В описании проекта укажите стек и дайте ссылку на исходный код, если площадка
позволяет: https://github.com/Aydenxvi/subguard.

PNG созданы командой `npm run capture:showcase` из каталога `frontend` при
запущенной статической сборке. Файл `showcase-bot-simulation-ru.png` содержит
пометку о симуляции прямо внутри изображения.

Владелец проекта добавил отдельный набор из 14 скриншотов в
[папке `owner`](owner/): `desktop-en-*.png` для ПК на английском и
`mobile-ru-*.jpeg` для телефона на русском. Если площадка допускает много
изображений, после обложки покажите обзор на ПК, подписки, защиту, возвраты,
аналитику и затем мобильные экраны. Для прямого просмотра отправляйте
[ссылку на галерею](https://aydenxvi.github.io/subguard/#gallery).
